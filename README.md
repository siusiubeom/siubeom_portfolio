## 📓 Field Notes

### Canine Seizure Detection

Vision AI로 반려견의 발작 영상을 연구하고 있어요. 42마리의 반려견과 350개 임상 영상으로 모델을 검증했고, ROC-AUC 0.865의 결과를 바탕으로 제1저자 논문을 준비하고 있습니다.

### VetSync

459명의 수의 의료진이 사용하는 입원환자 관리 시스템의 프론트엔드 개발을 리드하고 있어요. 웨스턴 동물병원, VIP 동물병원 등 국내 대형 동물병원의 실제 업무 흐름을 소프트웨어로 연결합니다.

VetU1의 세 번째 초기 멤버로 2026년 1월 합류했고, 7월에 정규직으로 전환했습니다.
